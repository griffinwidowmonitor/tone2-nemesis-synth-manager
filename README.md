## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Preset Library** | Organize Nemesis patches by synthesis engine and character |
| **Engine Notes** | Document synthesis engine combination settings per patch |
| **Arpeggio Config** | Track arpeggio and rhythm pattern settings for rhythmic presets |
| **Modulation Maps** | Document LFO and envelope modulation routing per complex patch |
